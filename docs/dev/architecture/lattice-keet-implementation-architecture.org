* Overview
This document is an implementation-oriented architecture specification for building
a Keet client as a WASM plugin for the Lattice editor. It assumes the Lattice
plugin system already exists and focuses on plugin/runtime interaction.

* Design Principles
- Thin WASM UI plugin
- Native networking runtime
- Capability-based host API
- Typed RPC
- Immutable state
- Event sourcing
- Async everywhere
- Crash isolation
- Deterministic rendering

* Host Responsibilities
- Load WASM
- Schedule async tasks
- Render panels
- Persist settings
- Provide secure capabilities
- Bridge RPC

* WASM Plugin Responsibilities
** UI
Conversation list, chat view, search, settings.

** State
Single AppState with reducers.

#+begin_src rust
struct AppState {
    identity: IdentityState,
    conversations: ConversationsState,
    active: Option<ConversationId>,
    messages: MessageStore,
    presence: PresenceStore,
    transfers: TransferStore,
}
#+end_src

* Runtime
Owns Peer networking, Hypercore replication, identity, storage,
attachments, media, synchronization and reconnection.

* RPC Contract
Every request contains request id, method and payload.

Methods:
- Login
- Logout
- ListConversations
- OpenConversation
- SendMessage
- EditMessage
- DeleteMessage
- UploadAttachment
- DownloadAttachment
- Search
- SubscribeEvents

* Event Bus
Events are append-only.

- Connected
- Disconnected
- ConversationAdded
- ConversationUpdated
- MessageReceived
- MessageEdited
- PresenceChanged
- TransferProgress

Reducers consume events to update state.
