#+TITLE: Keystroke latency
#+OPTIONS: toc:nil

* Why it matters
A keystroke should land on screen within one display frame, under any
background load. Below a frame, faster is imperceptible; above it, the
editor feels slow however fast it is on average.

* The frame budget
The budget at common refresh rates, computed rather than typed:

    print(f"{hz:>3} Hz  {1000 / hz:5.2f} ms")
